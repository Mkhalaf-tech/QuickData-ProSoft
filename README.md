# QuickData ProSoft v2.0
## حلول إدارة الأعمال الاحترافية — الإصدار الثاني

### 🚀 ما الجديد في الإصدار 2.0 (تحديث قوي)

- **لوحة تحكم احترافية** مع رسوم بيانية حقيقية (Chart.js)
- **نظام إشعارات متقدم** مع عداد وشارات حية
- **سجل نشاط كامل** لكل العمليات
- **إعدادات شركة قابلة للحفظ** (اسم، ضريبة، عملة، سنة مالية)
- **تصميم حديث** مستوحى من الهوية الاحترافية (كحلي + ذهبي دافئ)
- أنيميشن، وضع ليلي محسّن، وتأثيرات زجاجية
- **بحث سريع أقوى** (Ctrl+K) يشمل العملاء والمنتجات والفواتير
- **إجراءات سريعة محسّنة** (زر +)
- **تصدير واستيراد محسّن** للبيانات
- **تحسينات أداء** وواجهة أكثر سلاسة
- **دعم أفضل للجوال**

### تشغيل
```bash
cd project && npx serve .
```
أو افتح أي ملف HTML مباشرة في المتصفح.

### اختصارات
| الاختصار | الوظيفة |
|----------|---------|
| **Ctrl+K** | بحث سريع في الصفحات والسجلات |
| **Ctrl+D** | تبديل الوضع الليلي |
| **Esc** | إغلاق النوافذ والقوائم |
| زر **+** أسفل اليسار | إجراءات سريعة |

### بيانات
- حفظ تلقائي في المتصفح (localStorage)
- تصدير CSV من القوائم
- نسخة احتياطية JSON كاملة واستعادة من الإعدادات
- تحصيل فاتورة مبيعات ينشئ سند قبض تلقائياً
- سجل نشاط لكل العمليات المهمة
