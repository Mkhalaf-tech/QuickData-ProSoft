# QuickData ProSoft
## حلول إدارة الأعمال الاحترافية

### تشغيل
```bash
cd project && npx serve .
```

### اختصارات
- **Ctrl+K** بحث صفحات وسجلات
- **Ctrl+D** الوضع الليلي
- زر **+** أسفل اليسار إجراءات سريعة

### بيانات
- حفظ تلقائي في المتصفح
- تصدير CSV من القوائم
- نسخة احتياطية JSON واستعادة من الإعدادات
- تحصيل فاتورة مبيعات ينشئ سند قبض تلقائياً
