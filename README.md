# QuickData ProSoft
## حلول إدارة الأعمال الاحترافية

نظام ERP عربي كامل (Frontend) — RTL — Mock Data

### التشغيل
```bash
cd project
npx serve .
```

### المزايا
- لوحة أوامر Ctrl+K
- إشعارات ذكية
- وضع ليلي Ctrl+D
- إجراءات سريعة (FAB)
- محاسبة / مبيعات / مشتريات / مخزون / خزينة / مصروفات / أصول / موظفون / تقارير

### الهوية
- الاسم: QuickData ProSoft
- الشعار: QD
- الوصف: حلول إدارة الأعمال الاحترافية

### البنية
- js/mock-data.js — بيانات تجريبية

- css/erp-theme.css — نظام التصميم
